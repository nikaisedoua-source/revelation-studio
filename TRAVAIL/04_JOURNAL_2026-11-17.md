## 7. Bugs trouvés et corrigés pendant les essais réels

### 7.1 Import de médias sans effet

- **Symptôme** : après sélection, aucun média n'apparaissait.
- **Cause** : `fileInput.value = ''` vidait la `FileList` avant `importFiles(fileInput.files)`.
- **Correctif** : copie préalable `Array.from(fileInput.files)`.
- **Preuve** : 3 médias importés, visibles après rechargement et reconnexion.

### 7.2 Mauvaise piste vidéo

- **Symptôme** : la vidéo se posait sur V2.
- **Cause** : ordre des pistes candidates inversé pour tous les types.
- **Correctif** : V1 prioritaire pour vidéo/image, A1 pour audio.
- **Preuve** : clip vidéo sur V1, image sur V2, audio sur A1.

### 7.3 Export bloqué à 0 %

- **Symptôme** : l'overlay d'export restait à 0 %, la tête de lecture ne bougeait pas.
- **Cause** : `exportVideo()` mettait `S.exporting = true` puis appelait `play()`, qui retournait immédiatement si `S.exporting`.
- **Correctif** : `play(force)` avec `play(true)` réservé à l'export.
- **Preuve** : export MP4 de 5,0 s terminé, fichier `ftyp isom`, 1 920 × 1 080, 74 929 octets.

### 7.4 Paquet macOS qui plante

- **Symptôme** : `Révélation Studio.app` construit par electron-builder quittait immédiatement (SIGTRAP), alors que l'ASAR lancé avec Electron de développement fonctionnait.
- **Cause isolée** : nom de bundle accentué lors du packaging macOS.
- **Correctif** : `productName` ASCII `Revelation Studio` ; interface inchangée.
- **Preuve** : paquet reconstruit, processus vivant, serveur local HTTP 200.

### 7.5 Serveur Python non compilable

- **Symptôme** : `app/server.py` échouait à `py_compile`.
- **Cause** : deux imports et le décorateur de la route `/` étaient indentés hors de tout bloc.
- **Correctif** : remise à zéro de l'indentation ; compilation de tous les modules Python vérifiée.
- **Preuve** : `py_compile` silencieux, puis 29 tests Python OK dans un `.venv` créé depuis `requirements.txt`.

### 7.6 Ponts avec chemins personnels codés en dur

- **Symptôme** : les scripts Blender et After Effects pointaient vers l'ancien dossier `REVELATION_AI_STUDIO`.
- **Correctif** : chemins dérivés du fichier du pont (ou de `REVELATION_DATA_DIR`), `REVELATION_WHISPER_PYTHON` configurable, projet et chemins d'exemple rendus relatifs.
- **Preuve** : compilation Python OK ; les scripts utilisent désormais la racine du nouveau dossier consolidé.

### 9.5 Bug trouvé et corrigé pendant les essais

**Annuler l'étalonnage ne changeait rien.**

- **Symptôme** : après déplacement d'un curseur, `Annuler` laissait la nouvelle valeur, et un second `Annuler` pouvait retirer le clip entier.
- **Cause** : `oninput` modifiait `clip.grade` en direct ; `onchange` prenait ensuite l'instantané d'historique **après** cette mutation. L'état « avant » enregistré était donc déjà l'état modifié.
- **Correctif** : restaurer la valeur de départ avant d'appeler `commit`, puis appliquer la valeur finale dans la transaction.
- **Preuve** : exposition −50 → −40, `Annuler` restaure −50, `Rétablir` remet −40, nombre d'entrées d'historique cohérent.
